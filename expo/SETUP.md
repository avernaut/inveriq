# Booth and Laptop Setup

## Recommended hardware

Primary:

- laptop with Docker already tested;
- 16 GB RAM minimum recommended;
- power adapter;
- external monitor, ideally 24–27 inches;
- USB-C/HDMI adapter;
- mouse.

Backup:

- USB drive containing repository ZIP, reports, one-page, and demo video;
- second laptop if available;
- phone/tablet with backup video.

## Display layout

Use a single large browser window with the INVERIQ dashboard.

Recommended browser zoom: 100–110%.

Keep terminals on the laptop screen if using an external monitor.

### External display

Display only:

- INVERIQ dashboard;
- no source code;
- no terminal unless requested during a technical conversation.

### Laptop display

Keep:

- Terminal 1: Streamlit;
- Terminal 2: demo runner;
- optional Terminal 3: reset/status commands;
- backup video ready but hidden.

## Operating-system preparation

Before the Expo:

- disable automatic sleep on AC power;
- disable automatic system updates;
- disable desktop notifications;
- disable messaging pop-ups;
- disable automatic cloud-sync pop-ups;
- ensure Docker launches correctly after reboot;
- test without Wi-Fi.

## Browser preparation

- use a clean browser profile;
- close bookmarks bar if distracting;
- hide browser extensions;
- open only dashboard and Avernaut/INVERIQ website if available;
- full-screen the dashboard during the demo.

## Power and thermal considerations

- keep laptop on AC power;
- avoid unnecessary background applications;
- close IDEs during public demos if not needed;
- test ten consecutive demos to check thermal stability.

## Networking

The INVERIQ lab uses the local Docker network. Venue Wi-Fi must not be required.
