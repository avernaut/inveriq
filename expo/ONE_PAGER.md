# INVERIQ

## Verified Autonomous Defense

**AI decides. INVERIQ verifies.**

INVERIQ is a cybersecurity verification layer designed for autonomous response across IoT, Edge, Cloud, and operational infrastructure.

### The problem

AI-driven security systems can increasingly recommend or execute mitigation actions. But an action can stop an attack while also causing outages, breaking critical connectivity, or affecting legitimate users.

### The INVERIQ approach

INVERIQ places a deterministic verification layer between an AI-generated decision and infrastructure enforcement.

**Detect → Decide → Verify → Defend → Verify**

### Six verification gates

1. **Authorization** — Is the action permitted?
2. **Target** — Is the correct entity being affected?
3. **Reachability** — Do critical flows remain reachable?
4. **Availability** — Does the protected service remain available?
5. **Blast Radius** — Is legitimate impact within policy limits?
6. **Security Effectiveness** — Does the action actually mitigate the threat?

An action is executed only if all required gates pass.

### Demonstration scenarios

- Credential Brute Force — MITRE ATT&CK T1110
- Network Denial of Service — MITRE ATT&CK T1498
- Data Exfiltration — MITRE ATT&CK T1048

### Deployment vision

INVERIQ is designed to integrate with existing security and infrastructure controls rather than replace them.

Potential enforcement points include:

- firewalls;
- API gateways;
- Kubernetes;
- SDN controllers;
- cloud security controls;
- IoT/Edge gateways.

### Why it matters

**Both actions may stop the attack. Only one may be operationally safe. INVERIQ is designed to know the difference before execution.**
