# INVERIQ v0.8.0 — Real Traffic Generators & Effectiveness Measurement

v0.8.0 adds scenario-specific traffic generation inside the isolated Docker lab and measures mitigation effectiveness from the traffic actually produced.

## Scenarios

- Credential Brute Force — MITRE ATT&CK T1110
- Network Denial of Service — MITRE ATT&CK T1498
- Data Exfiltration — MITRE ATT&CK T1048

## Generate traffic

```bash
python scripts/traffic_generator.py --scenario brute-force --count 40
python scripts/traffic_generator.py --scenario ddos --count 40
python scripts/traffic_generator.py --scenario exfiltration --count 20
```

## Measure effectiveness

```bash
python scripts/benchmark_effectiveness.py --scenario brute-force
```

Alternative scenarios:

```bash
python scripts/benchmark_effectiveness.py --scenario ddos
python scripts/benchmark_effectiveness.py --scenario exfiltration
```

## Evidence

Each run records:

- attack request rate before mitigation;
- attack request rate after mitigation;
- attack-rate reduction;
- attack success rate before mitigation;
- attack success rate after mitigation;
- mitigation enforcement latency;
- trusted-service availability.

Reports:

```text
.demo-state/reports/effectiveness.csv
.demo-state/reports/<run-id>-effectiveness.json
```

## Safety

All traffic generation is limited to the isolated Docker network. All nftables actions remain inside `inveriq-gateway`. No host firewall modification is performed.

## Benchmark interpretation

Results are now derived from actual generated lab traffic. They are suitable for internal engineering evidence and live-demo reporting. For publication-grade claims, run repeated experiments with fixed host load, defined sample size, confidence intervals, and documented hardware/software versions.
