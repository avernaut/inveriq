# INVERIQ v0.6.0 — Measurement & Evidence

This release adds persistent evidence collection for every demo run.

## Captured KPIs

- Detection latency
- Decision latency
- Verification latency
- Enforcement latency
- Closed-loop response latency
- Attack rate before/after mitigation
- Attack reduction percentage
- Legitimate traffic rate before/after mitigation
- Availability percentage
- Blast radius
- Unsafe-action rejection status
- Verified-action execution status

## Reports

Each run produces:

- `.demo-state/reports/<run-id>.json`
- `.demo-state/reports/runs.csv`

The CSV accumulates runs across rehearsals.

## Commands

Run the demo:

```bash
demo/run_demo.sh --scenario brute-force --no-pause --keep-lab
```

Show aggregate metrics:

```bash
python scripts/metrics_summary.py
```

The Streamlit dashboard automatically displays the most recent metrics.

## Important interpretation note

v0.6.0 establishes the evidence pipeline and report format. Some telemetry values are currently generated inside the isolated demonstration framework rather than taken from production-grade packet counters. These values must not be presented as benchmark claims. The next measurement release should replace them with direct testbed instrumentation before publishing performance numbers externally.
